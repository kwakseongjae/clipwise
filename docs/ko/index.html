빠른 시작

60초 안에 시작하기

Clipwise를 설치하고 데모를 실행하거나 직접 시나리오를 작성해보세요.

1
설치
dev 의존성으로 추가하거나 npx로 설치 없이 사용할 수 있습니다.
bash
npm install -D clipwise
2
내장 데모 실행
내장 대시보드를 시네마틱 이펙트와 함께 녹화합니다. 설정 불필요.
bash
npx clipwise demo
npx clipwise demo --device iphone      # iPhone 목업
npx clipwise demo --device android     # Android 목업
npx clipwise demo --url https://kwakseongjae.github.io/clipwise/demo/  # 내 사이트
3
직접 시나리오 작성
템플릿을 생성하고 URL을 내 사이트로 변경한 후 녹화하세요.
bash
npx clipwise init                             # clipwise.yaml 생성
# clipwise.yaml 편집 — URL을 내 사이트로 변경
npx clipwise record clipwise.yaml -f mp4      # 녹화!

프로그래밍 API

typescript
import { ClipwiseRecorder, CanvasRenderer, encodeMp4, loadScenario } from "clipwise";

const scenario = await loadScenario("my-scenario.yaml");
const recorder = new ClipwiseRecorder();
const session  = await recorder.record(scenario);

const renderer = new CanvasRenderer(scenario.effects, scenario.output, scenario.steps);
const frames   = await renderer.composeAll(session.frames);
const mp4      = await encodeMp4(frames, scenario.output);
YAML 형식

시나리오 구조

시나리오는 4개 섹션으로 구성됩니다: 메타데이터, 이펙트, 출력, 스텝.

clipwise.yaml
name: "My Demo"
description: "선택 설명"

viewport:
  width: 1280    # 브라우저 너비 (기본: 1280)
  height: 800    # 브라우저 높이 (기본: 800)

effects:
  # 아래 "이펙트" 섹션 참조

output:
  format: mp4              # gif | mp4 | png-sequence
  width: 1280
  height: 800
  fps: 30                  # 1-60
  quality: 80              # 1-100 (MP4: CRF에 매핑)

steps:
  - name: "스텝 이름"
    actions:
      - action: navigate
        url: "https://example.com"
    captureDelay: 200       # 액션 후 대기(ms)
    holdDuration: 800       # 결과 화면 유지(ms)
    transition: none        # none | fade

액션

액션 파라미터 설명
navigateurl, waitUntil?URL로 이동
clickselector, delay?요소 클릭
typeselector, text, delay?텍스트 입력 (한 글자씩)
hoverselector요소에 마우스 올리기
scrolly?, x?, selector?, smooth?스크롤
waitduration대기 (ms)
screenshotname?, fullPage?캡처 마커
이펙트

시네마틱 이펙트

모든 이펙트는 선택사항이며 합리적인 기본값이 있습니다. 원하는 스타일로 조합하세요.

줌
커서를 따라가며 클릭 대상에 자동으로 줌인합니다.
followCursor autoZoom 
zoom:
  enabled: true
  scale: 1.8
  duration: 500
커서
커스텀 커서 + 클릭 리플 + 트레일 + 하이라이트 + 속도 조절.
trail highlight clickEffect 
cursor:
  enabled: true
  speed: "fast"
  trail: true
  highlight: true
배경
그라디언트/단색 패딩 + 라운드 코너 + 드롭 섀도.
gradient shadow 
background:
  type: gradient
  value: "linear-gradient(135deg,
    #667eea 0%, #764ba2 100%)"
  padding: 48
  borderRadius: 14
디바이스 프레임
브라우저, iPhone, iPad, Android 목업으로 녹화를 감쌉니다.
browser iphone android 
deviceFrame:
  enabled: true
  type: browser   # or iphone/ipad/android
  darkMode: true
키스트로크 HUD
타이핑 내용을 화면 하단에 실시간으로 표시합니다.
bottom-center 
keystroke:
  enabled: true
  position: bottom-center
  fontSize: 16
  fadeAfter: 1500
속도 램프
클릭 근처 슬로우모션, 유휴 구간 자동 빨리감기.
idleSpeed actionSpeed 
speedRamp:
  enabled: true
  idleSpeed: 3.0
  actionSpeed: 0.8
